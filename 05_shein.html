## Diagnóstico e decisões antes de corrigir Há duas colunas complementares de título, e a primeira parece quase vazia se observada sozinha. A maioria dos anúncios não tem URL; portanto não é possível usar um identificador de produto confiável em todas as linhas. Preços e descontos são texto. Ausência de desconto não equivale a desconto zero. Campos de ranking, cor e proposta comercial são esparsos e não serão descartados nem preenchidos com dados inventados. O pipeline padroniza texto, converte números, combina títulos e registra ausências, remove apenas duplicatas completas de anúncios e sinaliza outliers por categoria. Mantém as colunas de origem para auditoria. Uma linha repetida na mesma coleta não acrescenta informação sobre a oferta, mas os dados não permitem provar a identidade de todos os produtos. ## Funções reutilizáveis
def padronizar_textos(base):
    out=base.copy()
    for col in out.select_dtypes(include=['object','string']).columns:
        out[col]=out[col].astype('string').str.strip().str.replace(r'\s+',' ',regex=True).replace('',pd.NA)
    return out

def corrigir_tipos(base):
    out=base.copy()
    preco=out['price'].str.replace(',','',regex=False)
    out['preco_parse_invalido']=preco.notna() & ~preco.str.fullmatch(r'\$\d+(?:\.\d{1,2})?').fillna(False)
    out['preco_usd']=pd.to_numeric(preco.str.extract(r'^\$(\d+(?:\.\d{1,2})?)$',expand=False),errors='coerce')
    desconto=out['discount']
    out['desconto_parse_invalido']=desconto.notna() & ~desconto.str.fullmatch(r'-?\d+(?:\.\d+)?%').fillna(False)
    out['desconto_fracao']=pd.to_numeric(desconto.str.extract(r'^-?(\d+(?:\.\d+)?)%$',expand=False),errors='coerce')/100
    fora=out['desconto_fracao'].notna() & ~out['desconto_fracao'].between(0,1,inclusive='left')
    out['desconto_parse_invalido']=out['desconto_parse_invalido']|fora
    out.loc[fora,'desconto_fracao']=np.nan
    out['preco_invalido']=out.preco_usd.notna() & out.preco_usd.le(0)
    out.loc[out.preco_invalido,'preco_usd']=np.nan
    return out

def tratar_ausentes(base):
    out=base.copy()
    out['titulo']=out['goods-title-link--jump'].combine_first(out['goods-title-link'])
    out['titulo_chave']=out['titulo'].str.casefold()
    out['desconto_ausente']=out['desconto_fracao'].isna()
    out['preco_ausente']=out['preco_usd'].isna()
    out['titulo_ausente']=out['titulo'].isna()
    return out

def tratar_duplicatas(base):
    # Conservador: igualdade em TODOS os campos originais, já normalizados.
    # Não apaga itens só porque compartilham título/preço.
    campos_fonte=['goods-title-link--jump','goods-title-link--jump href','rank-title','rank-sub','price','discount','selling_proposition','color-count','goods-title-link','categoria','arquivo_origem']
    return base.drop_duplicates(subset=[col for col in campos_fonte if col in base.columns]).copy()

def tratar_outliers(base):
    out=base.copy()
    grupos=out.groupby('categoria')['preco_usd']
    q1=grupos.transform(lambda s:s.quantile(.25))
    q3=grupos.transform(lambda s:s.quantile(.75))
    iqr=q3-q1
    out['preco_outlier_iqr']=out.preco_usd.lt(q1-1.5*iqr)|out.preco_usd.gt(q3+1.5*iqr)
    return out

def criar_features(base):
    out=base.copy()
    out['log_preco']=np.log1p(out.preco_usd)
    out['desconto_informado']=out.desconto_fracao.notna()
    out['tem_desconto']=out.desconto_fracao.gt(0).astype('boolean')
    out.loc[out.desconto_fracao.isna(),'tem_desconto']=pd.NA
    return out

def pipeline(base):
    out=padronizar_textos(base)
    out=corrigir_tipos(out)
    out=tratar_ausentes(out)
    out=tratar_duplicatas(out)
    out=tratar_outliers(out)
    return criar_features(out)

def carregar_e_limpar(caminho, categoria):
    base=pd.read_csv(caminho)
    base['categoria']=categoria
    base['arquivo_origem']=Path(caminho).name
    for col in ['goods-title-link--jump','goods-title-link']:
        if col not in base.columns:
            base[col]=pd.Series(pd.NA,index=base.index,dtype='string')
    return pipeline(base)

## Relatório e respostas às perguntas de reflexão O pipeline preserva preços positivos e sinaliza caudas por categoria. Não aplica capping a anúncios caros, pois eles podem caracterizar linhas premium da oferta. As features log_preco e preco_outlier_iqr facilitam visualização e auditoria. tem_desconto permanece desconhecido quando a fonte não informou desconto. A tabela de negócio resume preços e, separadamente, apenas descontos observados; não representa descontos médios de todos os produtos nem faturamento. 1. O problema mais difícil de perceber foi a fragmentação dos títulos em duas colunas. Olhar apenas para a primeira sugeriria que quase todos os anúncios não têm nome. combine_first recupera o título disponível sem inventar texto, e o gráfico mede a melhora no mesmo conjunto de linhas. 2. A ordem importa. Primeiro é preciso converter preço para número: ordenar strings monetárias não equivale a ordenar valores. Imputar preços ausentes pela mediana antes do IQR concentraria valores no centro e poderia estreitar seus limites; prefiro não imputar preço neste estudo e calcular os limites nos valores conhecidos e válidos. A deduplicação ocorre antes dos quartis para evitar que cópias influenciem a distribuição. 3. Se o objetivo fosse contar produtos únicos, precisaria de IDs de produto/variante ou acesso à fonte para reconciliar anúncios, pois título igual não basta. Se fosse estudar qualidade da coleta, preservaria as duplicatas com sinalização e investigaria sua origem, em vez de removê-las da tabela de oferta. 4. Mantive metadados esparsos para auditoria. A melhora não consiste em fazer todo percentual de ausência chegar a zero; consiste em recuperar informação existente, corrigir tipos, evitar dupla contagem exata e explicitar incertezas. Não atribuo desconto zero ao que não foi observado.
## Síntese dos resultados executados A base passou de 8,380 para 8,137 anúncios após remover 243 cópias completas. A mediana de preço foi US$ 16.10 em eletrodomésticos e US$ 2.275 em eletrônicos: os eletrodomésticos desta coleta são tipicamente mais caros. O desconto mediano informado foi 28% nas duas categorias, porém a cobertura é diferente: 59.81% e 34.68%, respectivamente. Não extrapolo essa igualdade para descontos ausentes. Todos os títulos foram recuperados pela combinação das colunas, sem imputar nomes.
